# Block Guide checklist

Preencha esta lista somente depois de consultar a revisão oficial aplicável. Valores desconhecidos permanecem `PENDENTE_DE_CONFIRMACAO`.

| Campo | Valor atual | Evidência necessária |
| --- | --- | --- |
| Revisão do Block Guide | PENDENTE_DE_CONFIRMACAO | Título, versão e link/data de acesso |
| Revisão do Submission Guide | PENDENTE_DE_CONFIRMACAO | Título, versão e link/data de acesso |
| Formato oficial do pacote | PENDENTE_DE_CONFIRMACAO | Seção do guia |
| Schema/nome do arquivo de configuração | PENDENTE_DE_CONFIRMACAO | Exemplo oficial validado |
| Perfil Verilog/SystemVerilog | PENDENTE_DE_CONFIRMACAO | Versão e extensões aceitas |
| Top do design informado à plataforma | PENDENTE_DE_CONFIRMACAO | Configuração do projeto na plataforma |
| Top do testbench informado à plataforma | PENDENTE_DE_CONFIRMACAO | Configuração do projeto na plataforma |
| Forma de ordenar fontes | PENDENTE_DE_CONFIRMACAO | Regra do compilador/plataforma |
| Macros de compilação | PENDENTE_DE_CONFIRMACAO | Suporte e sintaxe documentados |
| `$readmemh` e caminhos relativos | PENDENTE_DE_CONFIRMACAO | Execução real com firmware |
| `$fatal`/`$error` e status de falha | PENDENTE_DE_CONFIRMACAO | Teste negativo controlado |
| `$dumpfile`/`$dumpvars` | PENDENTE_DE_CONFIRMACAO | Waveform real inspecionado |
| Plusargs | PENDENTE_DE_CONFIRMACAO | Execução com e sem argumento |
| Semântica de `initial` no fluxo alvo | PENDENTE_DE_CONFIRMACAO | Simulação e, se aplicável, síntese |
| Limite de duração da simulação | PENDENTE_DE_CONFIRMACAO | Documentação/observação |
| Limite de arquivos e tamanho | PENDENTE_DE_CONFIRMACAO | Documentação de upload |
| Wrapper/interface de bloco exigida | PENDENTE_DE_CONFIRMACAO | Especificação de integração |
| Evidências e critérios de aprovação | PENDENTE_DE_CONFIRMACAO | Submission Guide |
| Metadados/licença/autoria obrigatórios | PENDENTE_DE_CONFIRMACAO | Formulário de submissão |
| Regras de tag, versão e reenvio | PENDENTE_DE_CONFIRMACAO | Submission Guide |
| Requisitos físicos/OpenLane | PENDENTE_DE_CONFIRMACAO | Guia/PDK/fluxo alvo |

Os valores conhecidos localmente (`riscv_top`, `tb_core`, `systemverilog-2012`) são convenções do pacote deste repositório e não preenchem automaticamente os campos oficiais acima.
