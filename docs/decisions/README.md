# Registros de decisão

Crie um arquivo `NNNN-titulo-curto.md` antes de alterar microarquitetura,
interfaces externas ou premissas de síntese. Use:

```markdown
# Título

## Contexto
## Decisão
## Alternativas consideradas
## Consequências
## Impacto nos testes
## Impacto na síntese
```

Pipeline, cache, forwarding, hazards, interrupções, CSR, multiplicação/divisão,
barramento externo e separação Harvard sempre exigem um registro.
